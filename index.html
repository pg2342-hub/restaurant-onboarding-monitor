Restaurant onboarding monitor

A multi-location restaurant group signs on. Before any location goes live, its POS sales, distributor order guides, invoices, recipes, par levels and counts have to line up in one item catalog. This tool maps the vendor lines into the catalog (rules first, Claude for the rest, a person for anything unsure), says location by location whether the numbers can be trusted, and then checks the live data every day.

    Data

    The restaurant group, its locations, sales, recipes, invoices and counts are made up. Sysco, US Foods and Restaurant Depot are real distributors; the item codes, descriptions and prices are invented in the style of their order guides. The Claude replies are a recorded live run.

    Run it yourself

    Python 3.10 or later. From the repo folder:

    pip install -e ".[dev]"
python scripts/run_all.py
python -m onboarding.report sample_data/first_pull
pytest -q
